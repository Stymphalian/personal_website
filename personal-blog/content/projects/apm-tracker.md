## APM Tracker
I've gotten into Age of Empires 2 lately. It was one of my first computer games that
I ever played and I am pleasently surprised that there is a thriving competetive scene 
in the modern day. Microsoft did a re-make of the game with new graphics, and has been regularly 
been releasing DLC for the game.

Like most games these days it supports User-made mods to update the game with new functionality.
One thing that was missing was an APM (Actions Per Minute) tracker. I couldn't find 
any setting within the game, or as a MOD. I wanted some APM overlay during my game 
to help keep track of my speed in the game. It wasn't availble so with the "POWER of ROBOTS"
it was very simple to create an APM tracker app (completely vibe coded).

See below for how it looks.
Nothing fancy but it is nice that code is so cheap to create nowaday.
